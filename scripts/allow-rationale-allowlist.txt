# E4 rationale-on-suppression allowlist — pre-existing un-rationaled sites.
#
# INVARIANT-STATE PREAMBLE (read before trusting any entry here):
#   This file grandfathers production `#[allow(...)]` suppressions of the
#   shape/dead-code lints (too_many_lines, too_many_arguments, type_complexity,
#   dead_code, unused_*) that pre-date the E4 gate and carry no justifying
#   comment. The gate (scripts/check-allow-rationale.sh) enforces D4 only on
#   NEW/CHANGED suppressions; these keys exempt the legacy backlog so the gate
#   can land green without a mass refactor.
#
#   Keys are `path::symbol` (file + enclosing item name), NOT `path:line` —
#   line numbers drift on every refactor; the symbol is stable. The optional
#   trailing `# lints` annotation records which lints each key already covers;
#   adding a NEW lint to a keyed site is a NEW suppression and must carry its
#   own rationale (it is not grandfathered by the key).
#
#   The set of keys is NOT a frozen census. Counts and membership drift as code
#   is added, removed, and refactored. Re-derive the current set at use time:
#     grep -rnE '#\[allow\(.*(too_many_lines|too_many_arguments|type_complexity|dead_code|unused_)' \
#       crates/*/src --include='*.rs'
#   then drop hits at/below each file's first test-module boundary — both the
#   bare `#[cfg(test)]` and the `#[cfg(all(test, ...))]` forms (test scope is
#   out of gate scope) — and resolve each surviving site's enclosing item to
#   its `path::symbol` key. Sites that already carry a justifying comment (e.g.
#   a trailing inline `// ...` rationale) are recognized by the gate and need
#   NOT appear here.
#
#   This list is meant to SHRINK TO ZERO: as each grandfathered suppression is
#   either removed or given a real `// RATIONALE:` comment during the burndown,
#   delete its key. An empty file means the whole tree satisfies D4.
#
